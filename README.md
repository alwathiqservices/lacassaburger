# لاكاسا برجر — صفحة الاستقبال (lacassaburger)

صفحة روابط ثابتة (HTML + CSS + JavaScript فقط) لمطعم لاكاسا برجر — بدون Backend ولا خطوة Build.
هذا المشروع **منفصل تماماً** عن مشروع المنيو (`lacasanew`)؛ زر "تصفّح المنيو" فقط يفتح رابطه الخارجي.

## خطوات الرفع (مهم: حافظ على نفس رابط الصفحة)

1. **لا تُعِد تسمية المستودع** — يجب أن يبقى اسمه `lacassaburger` تحت حساب `alwathiqservices`،
   حتى يبقى الرابط `https://alwathiqservices.github.io/lacassaburger/` يعمل تماماً كما هو
   (وبالتالي تبقى رموز QR الحالية المطبوعة/المنشورة صالحة دون أي تغيير).
2. من صفحة المستودع على GitHub، احذف الملفات القديمة (index.html القديم) وارفع كل ملفات
   هذا المجلد بنفس البنية تماماً (لا تغيّر أسماء المجلدات `assets/` ولا مساراتها).
3. من Settings → Pages: تأكد أن المصدر هو Branch الرئيسي (main) والمجلد الجذر (/root) — كما هو مضبوط حالياً على الأغلب لأن الرابط يعمل مسبقاً.
4. انتظر دقيقة إلى دقيقتين حتى ينشر GitHub Pages النسخة الجديدة، ثم افتح الرابط للتأكد.
5. إن كان المتصفح قد خزّن نسخة قديمة (Service Worker سابق إن وُجد)، أول زيارة بعد الرفع تُحدّث
   الكاش تلقائياً بفضل `skipWaiting()` و`clients.claim()` في `sw.js` — لا حاجة لأي إجراء يدوي من الزوار.

## بنية الملفات

```
index.html                          → الصفحة نفسها (بدون شاشة افتتاحية تؤخر الوصول للمنيو)
style.css                           → الهوية السينمائية الداكنة (أسود/أحمر) وكل التنسيقات
script.js                           → زر المنيو (يراعي الاتصال)، زر التثبيت، تسجيل Service Worker
manifest.webmanifest                → إعدادات PWA (محصورة بمسار /lacassaburger/ فقط)
sw.js                                → تخزين مؤقت لصفحة الاستقبال نفسها فقط (Cache معزول باسم فريد)
assets/images/logo.png              → الشعار الأصلي (يُستخدم داخل الصفحة)
assets/images/burger-hero.png       → صورة الطعام الحقيقية في المشهد السينمائي
assets/icons/icon-192.png           → أيقونة PWA عادية 192×192
assets/icons/icon-512.png           → أيقونة PWA عادية 512×512
assets/icons/icon-maskable-512.png  → أيقونة Maskable (منطقة أمان أكبر لأقنعة أندرويد الدائرية)
assets/icons/apple-touch-icon-180.png → أيقونة آيفون 180×180
```

## ملاحظة مهمة بخصوص التصميم المطلوب

طلبت تصميماً مستوحى من أجواء "La Casa de Papel" يتضمن "شخصية بالقناع والزي الأحمر" في الخلفية.
لم أُضِف هذا العنصر تحديداً: قناع دالي + الزي الأحمر المميز هو تصميم شخصية محمية بحقوق فكرية
خاصة بالعمل الدرامي، وإعادة إنتاجه — ولو جزئياً كتفصيل خلفية — يُعتبر نسخاً لعنصر محمي.
بدلاً منه استخدمت: إضاءة حمراء درامية، تدرّج أسود-أحمر عميق، ومعالجة سينمائية (تعتيم أطراف
+ توهج خافت) على صورة برجر حقيقية، إضافة إلى شكل "خزنة" مجرّد مرسوم بالكامل بـ CSS (حلقات
دائرية عامة لا ترتبط بأي عمل أو شخصية) لإضفاء أجواء "الخطة المحكمة" دون أي إشكال حقوق نشر.

## التثبيت على الشاشة الرئيسية

- **أندرويد/كروم**: زر "أضف للشاشة الرئيسية" يظهر تلقائياً عند توفر حدث `beforeinstallprompt`
  (يتطلب HTTPS فعلياً — يعمل على GitHub Pages مباشرة) ويشغّل نافذة التثبيت الحقيقية للمتصفح.
- **آيفون/Safari**: لا يدعم iOS هذا الحدث؛ الزر يظهر ويفتح بطاقة إرشاد قصيرة (مشاركة ← إضافة
  إلى الشاشة الرئيسية) بدل الادّعاء بتثبيت تلقائي غير موجود على iOS.
- إن كانت الصفحة تعمل بالفعل كتطبيق مثبّت (`standalone`)، يختفي الزر تلقائياً.
- الاسم الظاهر عند التثبيت: **لاكاسا برجر**، والأيقونة: الشعار الأصلي كاملاً على خلفية بيضاء.

## الاختبارات التي تمّت فعلياً (متصفح آلي حقيقي - Playwright/Chromium)

- لا تمرير أفقي على 360/375/390/430/768/1440 بكسل.
- زر "تصفّح المنيو" يظهر ضمن الشاشة الأولى دون تمرير على كل هذه المقاسات.
- محاكاة User-Agent لآيفون: زر التثبيت يظهر ويفتح بطاقة الإرشاد الصحيحة.
- محاكاة `display-mode: standalone`: زر التثبيت يختفي تلقائياً.
- تسجيل Service Worker بنطاق `http://…/lacassaburger/` مضبوط بدقة (تحقّق مباشر من `registration.scope`).
- عزل الكاش: أنشأتُ يدوياً كاش وهمياً باسم مشروع آخر (`lacasa-shell-v2`) قبل تفعيل هذا الـ SW،
  وتأكدت أنه **لم يُحذف إطلاقاً** بعد التفعيل، بينما حُذفت فقط نسخة قديمة من كاش هذا المشروع نفسه.
- عمل الصفحة **بدون إنترنت بالكامل** بعد أول زيارة (تحقّق مباشر: قطع الاتصال ثم إعادة تحميل الصفحة).
- الضغط على "تصفّح المنيو" أثناء انقطاع الاتصال: يمنع الانتقال فعلياً ويظهر تنبيهاً واضحاً، ولا يفتح رابطاً ميتاً.
- صفر أخطاء JavaScript خلال كل ما سبق.

## ما لم أتمكن من اختباره على جهاز حقيقي

- تجربة زر "أضف للشاشة الرئيسية" الفعلية على Chrome/أندرويد حقيقي (محاكاة الحدث فقط في الاختبار الآلي).
- تجربة إرشاد iOS والتثبيت الفعلي على آيفون حقيقي عبر Safari.
- شكل الأيقونة الفعلي بعد التثبيت على شاشة رئيسية حقيقية (تم توليدها وفحصها بصرياً فقط كملفات PNG).
- سلوك GitHub Pages الفعلي بعد الرفع (اختبرت محلياً فقط بمحاكاة نفس بنية المسار `/lacassaburger/`).

أنصح بتجربة هذه النقاط يدوياً بعد الرفع مباشرة، وإخباري بأي ملاحظة لتعديلها فوراً.
